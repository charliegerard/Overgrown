# Overgrown 🌿

A Chrome extension that lets plants invade your abandoned tabs the longer you leave them unread. To get the page back, you have to slash through the plants with your mouse, as if trying to open an overgrown door. 

While a tab is more than 5% overgrown, the page behind the plants can't be used.

![Overgrown demo](/overgrown-extension-demo.gif)

## Install

1. Download the `dist` folder from this repo 
2. Open `chrome://extensions` and turn on Developer mode.
3. Click `Load unpacked` and pick the **`dist/`** folder.
